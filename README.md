# Rio Tri Prayogo_CRM
 
Aplikasi CRM berbasis web untuk mengelola leads, proyek, produk, dan pelanggan.
 
## Akses Aplikasi
 
Deployment: **https://rio-crm.vercel.app**

API: **https://riocrm-production.up.railway.app/**

## Fitur
 
- Dashboard statistik
- Manajemen Leads, Proyek, Produk, Pelanggan
- Export laporan ke Excel (khusus Manager)
- Role-based access (Manager & Sales)

## Tech Stack
 
- **Frontend**: React + Vite — deploy di Vercel
- **Backend**: Laravel 13 + PostgreSQL — deploy di Railway
- **Containerisasi**: Docker + Docker Compose
